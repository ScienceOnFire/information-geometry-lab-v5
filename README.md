# Information Geometry Lab V5
React / TypeScript / Vite. npm install; npm run dev. npm run build for deployment.
Preserves V2 dashboard and adds generation mixes, causal filtering, rolling partitions, Wasserstein, Bhattacharyya and numerical Jensen–Shannon distances, delay-coordinate shared AR companion operator and frequency-selective Fourier projection clustering. No exact Koopman modes or Koopman-Fisher metric are claimed. No mode gives a zero distance matrix (no accepted split). Scenario comparison uses Wasserstein, 16 ensemble runs, 15 s window ending at 18 s. Validation.txt records actual numerical runs.
S0 all SG; S1 two GFM; S2 three GFM and two GFL surrogates; S3 five GFM and three GFL surrogates. Equal unit rating assumed for penetration percentages. GFM is a virtual swing model; GFL is only a low-inertia damped phase-tracking surrogate, not a validated PLL/current-source model. Effective masses 2H, 1.2, 0.5; damping D, 3, 2.5. S2/S3 deliberately alter network coupling to represent changed electrical connectivity; effects cannot be attributed to inertia alone. All units use common base. Zero-transfer equilibrium and area displacement are idealized. Integration step 1 ms, output 20 ms. Causal filter is first-order high/low pass; offline option uses future samples. Ensemble statistics are simulation-only; sliding-window option uses one realization. Rolling replay is not a live PMU interface. AR roots are approximate and may be spurious. No independent grid benchmark, convergence study or browser build verified. Mutual information and phase-locking value not included.
